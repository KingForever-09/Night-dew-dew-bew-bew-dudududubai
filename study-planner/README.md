# 📓 สมุดงานนักเรียน (Study Planner)

เว็บแอปจัดการการบ้าน/งานที่มอบหมาย ลากวางเปลี่ยนสถานะได้ พร้อมตารางเรียน ตารางส่วนตัว และปฏิทิน — ใช้งานฟรี, ข้อมูลไม่หาย แม้ปิดเบราว์เซอร์หรือเปลี่ยนเครื่อง (เพราะเก็บบนฐานข้อมูลจริง ไม่ใช่ในเบราว์เซอร์)

ระบบนี้ใช้ **GitHub Pages** สำหรับแสดงเว็บไซต์ (ฟรี) และ **Supabase** สำหรับระบบสมัครสมาชิก/เข้าสู่ระบบและฐานข้อมูล (ฟรี สำหรับผู้ใช้จำนวนไม่มาก)

> ⚠️ หมายเหตุสำคัญ: GitHub Pages โฮสต์ได้แค่ไฟล์หน้าเว็บ (HTML/CSS/JS) เท่านั้น ไม่มีฐานข้อมูลในตัว ถ้าไม่ต่อกับ Supabase ข้อมูลจะหายทุกครั้งที่ปิดเบราว์เซอร์ ขั้นตอนด้านล่างนี้จึงต้องทำ **ทั้งสองส่วน** เพื่อให้ข้อมูลไม่หายและมีระบบล็อกอินจริง

---

## ภาพรวมไฟล์ในโปรเจกต์

```
├── index.html              หน้าเว็บหลักทั้งหมด
├── style.css                การจัดหน้าตา/สีสัน
├── app.js                    โค้ดการทำงานทั้งหมด (ล็อกอิน, ลากวาง, ปฏิทิน ฯลฯ)
├── config.js                 ใส่คีย์ของ Supabase ตรงนี้ (ทำในขั้นตอนที่ 2)
├── supabase-schema.sql       คำสั่งสร้างตารางฐานข้อมูล (ใช้ในขั้นตอนที่ 2)
└── README.md                  ไฟล์นี้
```

---

## ขั้นตอนที่ 1 — สร้างบัญชี Supabase และโปรเจกต์ใหม่

1. ไปที่ https://supabase.com แล้วกด **Start your project** สมัครด้วยอีเมลหรือ GitHub
2. กด **New project**
   - ตั้งชื่อโปรเจกต์ เช่น `study-planner`
   - ตั้งรหัสผ่านฐานข้อมูล (จดเก็บไว้ ใช้ตอนตั้งค่าขั้นสูงเท่านั้น เว็บของเราไม่ต้องใช้)
   - เลือก Region ใกล้ไทยที่สุด เช่น Singapore
   - กด **Create new project** รอประมาณ 1–2 นาที

## ขั้นตอนที่ 2 — สร้างตารางฐานข้อมูล

1. ในเมนูซ้ายของ Supabase กด **SQL Editor** → **New query**
2. เปิดไฟล์ `supabase-schema.sql` ที่ให้มา คัดลอกทั้งหมด แล้ววางในช่อง SQL Editor
3. กด **RUN** — ระบบจะสร้างตาราง `assignments`, `class_schedule`, `personal_schedule`, `calendar_marks` พร้อมตั้งค่าความปลอดภัย (Row Level Security) ให้อัตโนมัติ เพื่อให้แต่ละคนเห็นแค่ข้อมูลของตัวเอง

## ขั้นตอนที่ 3 — เปิดใช้งานระบบสมัครสมาชิก (Auth)

1. ในเมนูซ้าย กด **Authentication** → **Providers**
2. ตรวจสอบว่า **Email** เปิดใช้งานอยู่ (ค่าเริ่มต้นเปิดอยู่แล้ว)
3. แนะนำ (ไม่บังคับ): ไปที่ **Authentication → Settings** แล้วปิด "Confirm email" ชั่วคราวถ้าต้องการให้สมัครแล้วใช้งานได้ทันทีโดยไม่ต้องกดยืนยันอีเมล เหมาะสำหรับใช้ในห้องเรียน/กลุ่มเพื่อน

## ขั้นตอนที่ 4 — คัดลอกคีย์เชื่อมต่อมาใส่ในเว็บไซต์

1. ในเมนูซ้าย กด **Project Settings** (ไอคอนเฟือง) → **API**
2. คัดลอกค่า 2 ค่านี้:
   - **Project URL** (เช่น `https://abcxyz.supabase.co`)
   - **anon public key** (คีย์ยาว ๆ ขึ้นต้นด้วย `eyJ...`)
3. เปิดไฟล์ `config.js` แล้วแก้ไขเป็นค่าของคุณ:

```js
window.SUPABASE_CONFIG = {
  url: "https://abcxyz.supabase.co",
  anonKey: "eyJhbGciOi..."
};
```

4. บันทึกไฟล์ — เสร็จแล้วสำหรับฝั่งฐานข้อมูล!

> 🔒 คีย์ `anon public key` ปลอดภัยที่จะใส่ในเว็บฝั่งผู้ใช้ (client-side) เพราะ Supabase ป้องกันด้วย Row Level Security ที่ตั้งไว้แล้วในขั้นตอนที่ 2 — คนอื่นจะไม่สามารถเห็นหรือแก้ข้อมูลของคุณได้

## ขั้นตอนที่ 5 — อัปโหลดขึ้น GitHub

### ถ้ายังไม่มีบัญชี GitHub
สมัครฟรีที่ https://github.com/signup

### สร้างที่เก็บ (Repository) ใหม่
1. ไปที่ https://github.com/new
2. ตั้งชื่อ repository เช่น `study-planner`
3. เลือก **Public**
4. **ไม่ต้อง** ติ๊กสร้าง README (เพราะเรามีไฟล์ครบแล้ว)
5. กด **Create repository**

### อัปโหลดไฟล์ (เลือกวิธีใดวิธีหนึ่ง)

**วิธีที่ 1 — อัปโหลดผ่านเว็บ (ง่ายสุดสำหรับมือใหม่)**
1. ในหน้า repository ที่สร้างใหม่ กด **uploading an existing file**
2. ลากไฟล์ทั้งหมด (`index.html`, `style.css`, `app.js`, `config.js`, `supabase-schema.sql`, `README.md`) ไปวาง
3. เลื่อนลงกด **Commit changes**

**วิธีที่ 2 — ใช้ Git ผ่าน command line**
```bash
git init
git add .
git commit -m "เริ่มต้นสมุดงานนักเรียน"
git branch -M main
git remote add origin https://github.com/USERNAME/study-planner.git
git push -u origin main
```
(แทน `USERNAME` ด้วยชื่อผู้ใช้ GitHub ของคุณ)

## ขั้นตอนที่ 6 — เปิดใช้งาน GitHub Pages

1. ในหน้า repository ไปที่ **Settings** → เมนูซ้าย **Pages**
2. หัวข้อ **Build and deployment** → **Source** เลือก **Deploy from a branch**
3. **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที แล้วรีเฟรชหน้า จะเห็นลิงก์เว็บไซต์ของคุณ เช่น
   `https://USERNAME.github.io/study-planner/`
5. เปิดลิงก์นั้น สมัครสมาชิกและเริ่มใช้งานได้เลย! 🎉

## วิธีใช้งานเว็บไซต์

| ส่วน | การใช้งาน |
|---|---|
| 📋 กระดานงาน | กด "+ เพิ่มงานใหม่" กรอกวิชา ชื่องาน กำหนดส่ง รายละเอียด และเลื่อนแถบเพื่อกำหนด % ความคืบหน้า จากนั้น **ลากการ์ด** ไปวางในคอลัมน์อื่นเพื่อเปลี่ยนสถานะได้ทันที |
| 🏫 ตารางเรียน | เพิ่มวิชาในแต่ละวัน ระบบจะโชว์อัตโนมัติที่หัวเว็บว่าตอนนี้กำลังเรียนวิชาอะไร เหลือเวลาอีกกี่นาที |
| 🎯 ตารางส่วนตัว | เพิ่มกิจกรรมส่วนตัวประจำสัปดาห์ เช่น ซ้อมกีฬา ติวพิเศษ เวลาพักผ่อน |
| 📅 ปฏิทิน | จุดสีแดงคือวันที่มีงานครบกำหนด คลิกวันที่เพื่อดูงานวันนั้น หรือทำเครื่องหมาย "ยุ่ง"/"ว่าง" เพื่อวางแผนเวลา |

ข้อมูลทั้งหมดถูกบันทึกลง Supabase ทันทีที่กดบันทึก ไม่ว่าจะเข้าเว็บจากมือถือ แท็บเล็ต หรือคอมพิวเตอร์เครื่องไหน ก็จะเห็นข้อมูลเดิมเมื่อเข้าสู่ระบบด้วยบัญชีเดียวกัน และประวัติการล็อกอิน/ข้อมูลงานจะไม่ถูกลบเองเด็ดขาด

## แก้ปัญหาเบื้องต้น

- **หน้าเว็บขึ้นแต่กดสมัคร/ล็อกอินไม่ได้** → ตรวจสอบว่าใส่ `url` และ `anonKey` ใน `config.js` ถูกต้อง ไม่มีช่องว่างเกิน และไม่ลืมเซฟไฟล์ก่อนอัปโหลด
- **สมัครแล้วต้องรอยืนยันอีเมลตลอด** → ไปปิด "Confirm email" ตามขั้นตอนที่ 3
- **หน้าเว็บ 404 หลังตั้งค่า Pages** → รอ 2–3 นาทีแล้วลองรีเฟรชอีกครั้ง ตรวจสอบว่าเลือก branch/`root` ถูกต้อง
- **อยากเพิ่มเพื่อนให้ใช้งานร่วมกัน** → แค่ส่งลิงก์เว็บไซต์ให้เพื่อน แต่ละคนสมัครบัญชีของตัวเอง ข้อมูลจะแยกกันอัตโนมัติ

## อัปเดตเว็บไซต์ในอนาคต

แก้ไขไฟล์ที่ต้องการ แล้วอัปโหลดทับผ่านหน้าเว็บ GitHub (**Add file → Upload files**) หรือ `git push` อีกครั้ง — GitHub Pages จะอัปเดตเว็บให้อัตโนมัติภายในไม่กี่นาที ข้อมูลใน Supabase จะไม่ได้รับผลกระทบใด ๆ

ขอให้เรียนสนุกและส่งงานทันทุกชิ้นนะครับ/คะ 🎓
